# 开发指南（中文）

## 1. 目录结构
- `frontend/`：前端（Vite + React）
- `backend/`：后端（Java + Maven）
- `docs/`：项目文档
- `docker-compose.yml`：一键编排

## 2. 本地启动（推荐 Docker）
在项目根目录执行：
```bash
docker compose up -d --build
```

访问：
- 前端：`http://localhost:3514/`
- 后端：`http://localhost:8514/api/health`

## 3. 前端开发

### 3.1 安装依赖
```bash
pnpm -C frontend install
```

### 3.2 开发模式
```bash
pnpm -C frontend dev
```

### 3.3 构建
```bash
pnpm -C frontend run build
```

### 3.4 离线环境说明

**依赖离线安装**

项目根目录内置 pnpm content-addressable 商店 `.pnpm-store/`，且 `frontend/.npmrc`
已将 `store-dir` 指向它。在无法访问 npm 源的机器上（如 macOS arm64 开发机）：

```bash
pnpm -C frontend install --offline --frozen-lockfile
```

`package.json` 中配置了 `pnpm.supportedArchitectures`（darwin/linux/win32 × arm64/x64，
glibc/musl），因此商店内同时缓存了各平台的 Rollup / esbuild 原生二进制，
可避免 `Cannot find module @rollup/rollup-darwin-arm64` 这类“在 Linux 打包依赖、
在 macOS 使用”导致的原生模块缺失问题。

若依赖版本更新，需要在有网络的机器上重新预热商店后再分发：

```bash
pnpm -C frontend install           # 按 supportedArchitectures 拉取全部目标平台二进制
# .pnpm-store 即自动更新，随项目一起拷贝到离线环境
```

**地图离线底图**

`frontend/public/tiles/` 内置重庆市区 z8–z14 的 OpenStreetMap 瓦片（约 3.1MB）。
前端默认优先加载在线 OSM 瓦片，连续加载失败（或浏览器处于离线状态）时自动切换到
内置瓦片，恢复联网后自动切回在线图层；覆盖范围外的位置用透明瓦片兜底，不影响
节点与路线展示。覆盖范围与重新生成方式见 `frontend/public/tiles/README.md`。

## 5. 数据文件维护

### 5.1 节点（必需）
路径：`backend/src/main/resources/nodes.csv`

必需列：
- `id`：节点唯一 ID（建议大写英文 + 下划线）
- `name`：展示名称（中文）
- `lat` / `lng`：经纬度（小数）

可选列：`type`、`desc`

### 5.2 边（可选）
路径：`backend/src/main/resources/edges.csv`

必需列：
- `from`：起点 ID
- `to`：终点 ID

可选权重列：
- `distance_meters`（推荐）

注意：如果 `edges.csv` 缺失或为空，系统会按地理距离自动生成边。

## 6. 实施计划（合并）

### 6.1 目标
- 交付可运行的“重庆旅游线路规划系统”，支持一键启动、节点展示、路径规划与结果可视化

### 6.2 范围
- 前端：地图与控制面板、状态管理、错误兜底、中文化
- 后端：CSV 数据加载、数据库持久化、图构建、最短路径 API
- 运维：Docker Compose 一键启动、前端反代后端、环境变量配置

### 6.3 关键决策
- 数据输入采用 CSV（`nodes.csv` / `edges.csv`），兼容无边数据时的自动构图兜底
- 后端图算法采用 Dijkstra（节点规模小、实现清晰、可解释）
- 前端使用 Ant Design + React-Leaflet，结合 ErrorBoundary 保障稳定性

### 6.4 验收标准
- `docker compose up -d --build` 后：前端可访问、后端健康检查通过
- `/api/nodes` 返回非空节点列表
- `/api/path` 能返回可解释的路径结果；非法参数返回中文错误
- 文档齐全：架构/设计/开发/测试/用户手册/README

## 7. 任务清单（合并）
